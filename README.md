## 📱 Deskripsi

**Avatar** merupakan project aplikasi Android yang dibuat untuk memenuhi tugas pada mata kuliah Pemrograman Aplikasi Mobile. Project ini dikembangkan menggunakan Android Studio dan menggunakan sistem build **Gradle**.

## 🛠️ Teknologi yang Digunakan

* **Android Studio**
* **Kotlin**
* **Gradle**
* **Android SDK**


## 🚀 Cara Menjalankan Project

1. Clone repository ini:

```bash
git clone https://github.com/calyamaida/Avatar.git
```

2. Buka folder project menggunakan **Android Studio**.

3. Tunggu proses **Gradle Sync** selesai.

4. Hubungkan perangkat Android atau jalankan **Android Emulator**.

5. Jalankan aplikasi dengan menekan tombol **Run ▶** pada Android Studio.
